# Linux and Shell Programming (CET216)

Bilingual study sheet for the CET216 Linux and Shell Programming course.

## Description

This repository contains a single self-contained HTML study guide for Linux and Shell Programming.  
The guide includes English and Arabic explanations, lecture summaries, commands, Bash scripts, lab examples, security notes, and final revision questions.

## Contents

- Course overview
- Chapter-by-chapter summaries
- Linux commands table
- Bash and shell script examples
- Configuration snippets
- Security notes
- Final revision section
- Quick revision checklist

## How to Use

Open the file directly in any web browser:

```text
syllabus_summary.html
````

No internet connection is required.

**Course:** CET216 Linux and Shell Programming
