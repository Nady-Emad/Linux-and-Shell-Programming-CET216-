Course Overview / نظرة عامة على المادة

English Summary

This course teaches Linux command-line work and shell programming. It covers Linux concepts, distributions, installation environment, file system hierarchy, GUI vs shell access, command syntax, file and directory management, help/documentation, redirection, pipelines, permissions, users and groups, text editors, shell scripting, variables, arrays, operators, functions, processes, jobs, priorities, archives, links, and backup-focused scripts.

الملخص بالعربي

المادة تشرح التعامل مع لينكس من سطر الأوامر وبرمجة الشل. وتشمل مفاهيم لينكس، التوزيعات، بيئة التثبيت، شجرة نظام الملفات، الوصول من GUI أو Shell، صيغة الأوامر، إدارة الملفات والمجلدات، المساعدة والتوثيق، إعادة التوجيه، الـ pipelines، الصلاحيات، المستخدمين والمجموعات، المحررات، سكربتات الشل، المتغيرات، المصفوفات، المعاملات، الدوال، العمليات، الـ jobs، الأولويات، الأرشفة، الروابط، وسكربتات النسخ الاحتياطي.

Chapter-by-Chapter Summary / ملخص فصل بفصل

Session / Chapter 1

Linux Concepts, Installation, and System Access

Introduces Linux, open source, GNU/GPL, distributions, Red Hat/Fedora/community versions, Unix/Linux/Windows comparison, file system hierarchy, hard partitioning, swap, VMware/RHEL installation, GUI access, shell access, virtual consoles, and command prompt structure.

Practical concepts: VMware setup, virtual consoles, prompt meaning, whoami, w, cd, pwd, ls, date, cal, cat, head, tail, less, wc.

Security concepts: root account, file permissions, swap/partition decisions, system access, and Linux security advantages.

مفاهيم لينكس والتثبيت والوصول للنظام

يعرض لينكس والمصدر المفتوح وGNU/GPL والتوزيعات وإصدارات Red Hat/Fedora/community والمقارنة بين Unix/Linux/Windows وشجرة الملفات والتقسيم وswap والتثبيت على VMware/RHEL والوصول من GUI أو Shell والطرفيات الافتراضية وشكل prompt.

مفاهيم عملية: إعداد VMware، الطرفيات الافتراضية، معنى prompt، وأوامر whoami و w و cd و pwd و ls و date و cal و cat و head و tail و less و wc.

مفاهيم أمنية: حساب root، صلاحيات الملفات، قرارات التقسيم وswap، الوصول للنظام، وميزات أمان لينكس.

Session / Chapter 2

Managing Files, Directories, Paths, Links, and Help

Covers relative and absolute paths, file/directory operations, globbing, hidden files, symbolic and hard links, colors of file types, help commands, local documentation, and practical tasks.

Practical concepts: touch, mkdir, cp, mv, rm, ln, ln -s, man, info, pinfo, --help, /usr/share/doc.

Security concepts: permission denied troubleshooting, symbolic link risks, careful deletion, and knowing what file you are editing.

إدارة الملفات والمجلدات والمسارات والروابط والمساعدة

يتناول المسارات المطلقة والنسبية، أوامر الملفات والمجلدات، globbing، الملفات المخفية، الروابط الرمزية والصلبة، ألوان أنواع الملفات، أوامر المساعدة، التوثيق المحلي، والتدريبات العملية.

مفاهيم عملية: touch و mkdir و cp و mv و rm و ln و ln -s و man و info و pinfo و --help و /usr/share/doc.

مفاهيم أمنية: حل مشاكل permission denied، مخاطر soft links، الحذر من الحذف، ومعرفة الملف قبل تعديله.

Session / Chapter 3

Text Files, Redirection, Pipelines, Editors, and Permissions

Explains stdin/stdout/stderr, redirection symbols, combining files, find/grep usage, pipelines, text editors from shell prompt, vi/vim modes, and basic/special permissions.

Practical concepts: >, >>, 2>, &>, 2>/dev/null, |, cat, grep, wc, vim, vi, nano, gedit, chmod.

Security concepts: stderr handling, safe overwrite vs append, permissions r/w/x, setuid/setgid/sticky bit concepts.

الملفات النصية وإعادة التوجيه والـ pipelines والمحررات والصلاحيات

يشرح stdin/stdout/stderr ورموز إعادة التوجيه ودمج الملفات واستخدام find/grep والـ pipelines ومحررات النص من الشل وأوضاع vi/vim والصلاحيات الأساسية والخاصة.

مفاهيم عملية: > و >> و 2> و &> و 2>/dev/null و | و cat و grep و wc و vim و vi و nano و gedit و chmod.

مفاهيم أمنية: التعامل مع stderr، الفرق بين overwrite و append، صلاحيات r/w/x، ومفاهيم setuid/setgid/sticky bit.

Session / Chapter 4

Local Users, Groups, Passwords, Shadow File, and Sudo

Covers user types, UID ranges, primary and secondary groups, user/group creation, modification, deletion, password policies, login shells, shadow file fields, sudo, wheel group, and admin logs.

Practical concepts: useradd, passwd, usermod, userdel, groupadd, groupmod, groupdel, gpasswd, chage, sudo, /etc/passwd, /etc/shadow, /etc/group, /etc/sudoers.

Security concepts: encrypted passwords, account locking, password aging, no-login shell, least privilege, sudo logging.

المستخدمون والمجموعات وكلمات المرور وملف shadow و sudo

يتناول أنواع المستخدمين، نطاقات UID، المجموعات الأساسية والثانوية، إنشاء وتعديل وحذف المستخدمين والمجموعات، سياسات كلمات المرور، login shells، حقول ملف shadow، sudo، wheel group، وسجلات الإدارة.

مفاهيم عملية: useradd و passwd و usermod و userdel و groupadd و groupmod و groupdel و gpasswd و chage و sudo و /etc/passwd و /etc/shadow و /etc/group و /etc/sudoers.

مفاهيم أمنية: كلمات المرور المشفرة، قفل الحساب، password aging، شل no-login، أقل صلاحية، وتسجيل أوامر sudo.

Sessions 5–6 + Labs 5–9

Shell Programming, Variables, Decisions, Loops, and Functions

Covers shell types, creating and running scripts, shebangs, editors, variables, readonly variables, special variables, arrays, arithmetic/relational/boolean/string/file operators, if/elif/else, case, functions, local/global variables, and practical lab scripts.

Practical concepts: #!/bin/bash, #!/usr/bin/env bash, chmod +x, ./script.sh, read, echo, $0, $1, $#, $?, $RANDOM, for, while, until, break, continue, functions.

Security concepts: silent password input, input validation, quoting variables, checking files before editing or deleting.

برمجة الشل والمتغيرات والشروط والحلقات والدوال

يتناول أنواع الشل، إنشاء وتشغيل السكربت، shebang، المحررات، المتغيرات، readonly، المتغيرات الخاصة، المصفوفات، المعاملات الحسابية والمنطقية والنصية ومعاملات الملفات، if/elif/else، case، الدوال، المتغيرات المحلية والعامة، وسكربتات اللابات.

مفاهيم عملية: #!/bin/bash و #!/usr/bin/env bash و chmod +x و ./script.sh و read و echo و $0 و $1 و $# و $? و $RANDOM و for و while و until و break و continue والدوال.

مفاهيم أمنية: إدخال كلمة المرور بصمت، التحقق من الإدخال، وضع المتغيرات بين quotes، وفحص الملفات قبل التعديل أو الحذف.

Chapter 7 / Process Notes

Monitoring and Managing Linux Processes

Covers process definition, PID, PPID, child process, systemd as first system process on RHEL7, listing processes, real-time monitoring, GUI monitoring, jobs, foreground/background processes, signals, killing processes, and process priorities.

Practical concepts: echo $$, bash, ps, ps aux, ps -ef, pstree, pgrep, pidof, top, jobs, fg, bg, kill, pkill, killall, nice, renice.

Security concepts: root can affect all processes, SIGKILL must be used carefully, process ownership matters, and background processes may detach from terminal.

مراقبة وإدارة عمليات لينكس

يتناول تعريف العملية، PID، PPID، child process، كون systemd أول عملية في RHEL7، عرض العمليات، المراقبة اللحظية، المراقبة الرسومية، jobs، العمليات الأمامية والخلفية، الإشارات، قتل العمليات، وأولويات العمليات.

مفاهيم عملية: echo $$ و bash و ps و ps aux و ps -ef و pstree و pgrep و pidof و top و jobs و fg و bg و kill و pkill و killall و nice و renice.

مفاهيم أمنية: root يستطيع التأثير على كل العمليات، يجب الحذر مع SIGKILL، ملكية العملية مهمة، والعمليات الخلفية قد تنفصل عن الطرفية.

Command syntax and chaining

$ command -option arguments
# command -option arguments
cmd1 ; cmd2
cmd1 && cmd2
cmd1 || cmd2
command > continued command

; runs sequentially, && runs next only on success, || runs next only on failure, and backslash continues a command on the next line.

صيغة الأمر وربط الأوامر

الرمز ; يشغل الأوامر بالتتابع، و && يشغل الأمر التالي عند نجاح السابق، و || يشغل الأمر التالي عند فشل السابق، والشرطة العكسية تكمل الأمر في السطر التالي.

Redirection and pipeline

command > file        # override stdout
command >> file       # append stdout
command 2> errors     # redirect stderr
command 2> /dev/null  # discard errors
command &> file        # stdout + stderr
command >> file 2>&1  # append both
command | filter      # pipeline

إعادة التوجيه والـ pipeline

> يستبدل الخرج، >> يضيف للملف، 2> يوجه الأخطاء، /dev/null يتجاهل الخرج أو الأخطاء، &> يوجه stdout و stderr معًا، و | يرسل خرج أمر إلى أمر آخر.

Account file formats

/etc/shadow fields:

صيغ ملفات الحسابات

ملف /etc/passwd يحتوي بيانات المستخدم الأساسية، و /etc/group يحتوي بيانات المجموعات، و /etc/shadow يحتوي كلمة المرور المشفرة وسياسات العمر والانتهاء.
